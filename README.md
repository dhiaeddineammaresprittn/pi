#  Esprit Dashboard – Admission & Employabilité

> Application Angular conçue pour visualiser, analyser et améliorer l'admission et l'employabilité des étudiants.

---

##  Objectif

Ce tableau de bord vise à aider les établissements d'enseignement à :
- Suivre les **taux d’admission** par programme.
- Analyser les **taux d’employabilité** par filière ou profil.
- Visualiser les **compétences clés** demandées dans chaque secteur.

---

## 🖥 Fonctionnalités principales

✅ Visualisation des taux d’admission et d’employabilité  
✅ Comparaison entre filières, niveaux et promotions
