# 🎯 Deep Learning - Employability & Career Sector Prediction

Ce module utilise des modèles de deep learning pour :
1. Classifier un texte selon un **secteur professionnel**.
2. Prédire un **score d’employabilité** basé sur la pertinence du texte.

## 🧠 Modèles Utilisés

- **SectorClassifier** : modèle LSTM pour prédire le secteur professionnel (83 classes).
- **EmployabilityScorer** : régression dense pour estimer un score d’employabilité (0–100).
- **SentenceTransformer** : encodage sémantique du texte avec `all-mpnet-base-v2`.
